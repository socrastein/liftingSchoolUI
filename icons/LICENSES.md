# Where the icons come from

Each file is named exactly as its source names it, so any icon can be looked up there by its file name.

| Source                                  | Licence                                                                  | Icons                                                   |
| --------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| [Lucide](https://lucide.dev)            | ISC, with MIT for the icons it took from Feather (`licences/lucide.txt`) | every file whose `<svg>` has the `lucide` class         |
| [Simple Icons](https://simpleicons.org) | CC0 (public domain): no notice needed                                    | `bluesky`, `facebook`, `github`, `instagram`, `youtube` |
| The Lifting School                      | not licensed for reuse: the business's own logo                          | `logo`, and everything in `app/` (made from it)         |

Interface icons come from Lucide, so the set keeps one drawing style. Brand marks come from Simple Icons, because Lucide removed
its brand icons in version 1.0. The drawings of brand marks are public domain, but the brands themselves are trademarks, so use
them only to link to that brand, as their owners' guidelines allow.
